# SAT 2026 Digital — What Changed & How to Prepare

## Format (Digital SAT / Bluebook)
- **4 modules:** Module 1 RW → Module 2 RW (adaptive) → Module 3 Math → Module 4 Math (adaptive)
- **Reading & Writing:** 54 questions total; 2 modules (25 min / 25 min); adaptive difficulty
- **Math:** 44 questions total; 2 modules (35 min / 35 min); calculator permitted throughout (Desmos embedded); adaptive
- **Question types:** Multiple choice (4 options) + Student-Produced Responses (SPR / grid-ins)

## All Question Types (2026 Coverage)
| Skill | RW Type | Math Type |
|---|---|---|
| Craft & Structure | Main purpose, function, word-in-context | — |
| Information & Ideas | Evidence, inference, quantitative | Problem solving, statistics |
| Expression of Ideas | Transitions, synthesis, organization | — |
| Standard English Conventions | Modifiers, verbs, pronouns, punctuation | — |
| Algebra | — | Linear, systems, functions |
| Advanced Math | — | Quadratics, nonlinear, functions |
| Problem Solving & Data Analysis | — | Statistics, probability, ratios, graphs |
| Geometry & Trigonometry | — | Triangles, circles, coordinate, trig ratios |

## 2026 Tools & Features
- **Desmos Calculator:** Integrated; no manual graphing needed;
- **Bluebook App:** Practice on device; timer sync; no paper
- **Flag / Mark:** Bookmark hard questions; return later
- **Highlighter / Pen:** Digital annotation (use portal toolbar)
