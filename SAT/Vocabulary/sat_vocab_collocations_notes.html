SAT Vocabulary — Key Words by Category

domain: SATtarget_level: Score 700+topic: SAT Vocabulary — High-Frequency Words & Collocationsdate_created: 2026-09-13content_type: Vocabulary / Collocations Study Guide

Craft & Structure / Reading (Academic)

  • resilient = able to recover; opposite fragile
  • profound = deep / far-reaching
  • nuance = subtle distinction
  • paradox = apparent contradiction
  • empirical = based on observation/data

Information / Evidence

  • correlation = relationship / association (not causation)
  • inference = conclusion drawn from evidence
  • anomaly = deviation from norm
  • aggregate = total / combined
  • disparate = distinct / different

Expression / Rhetoric

  • concede = admit / acknowledge
  • pivot = turn / shift direction
  • coherent = logically consistent
  • synthesize = combine into unified whole
  • rhetorical = intended to persuade / effect

Math / Technical

  • proportion = ratio / part-to-whole
  • inverse = opposite / reciprocal relationship
  • nonlinear = not straight-line
  • variable = changing / unknown quantity
  • constant = unchanging value

Collocations (Common Pairs)

  • strong evidence (not big evidence)
  • draw a conclusion (not make a conclusion)
  • in support of (not in favor for)
  • account for (explain / make up)
  • leading to (causing / resulting in)
